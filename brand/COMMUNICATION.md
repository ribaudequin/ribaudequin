# Bandua Studio — Communication Guidelines

## Voice

**Mixed** — technical when talking about code, personal when talking about projects.

### Principles

| Principle | Description |
|---|---|
| **Clear** | Simple, direct language. No unnecessary jargon. |
| **Precise** | Concrete facts. No exaggeration or vague promises. |
| **Personal** | Approachable and warm. Like talking to a friend you trust. |
| **Trustworthy** | Transparent about what is made, how it is made, and why. |

### When to use each register

| Context | Register | Example |
|---|---|---|
| **Code/documentation** | Technical | "Offline validator for Portuguese identifiers." |
| **Social media** | Personal | "Things I make with care, built to last." |
| **READMEs** | Mixed | "Simple tools, made with care. Things that last." |
| **Customer support** | Personal | "Thanks for the support. I'll look into that." |

## README Guidelines

### Structure

```markdown
# Project Name

One-line description of what it does.

## What it does

Brief explanation of the problem it solves.

## Features

- Feature 1
- Feature 2
- Feature 3

## Installation

\```bash
install command
\```

## Usage

\```bash
usage example
\```

## License

MIT
```

### Style

- **Title:** Project name in lowercase
- **Description:** One sentence, clear and direct
- **Features:** Short list, no fluff
- **Code:** Code blocks with syntax highlighting
- **Language:** English only

### Example

```markdown
# clavis

Encrypted notes that stay on your device.

## What it does

clavis is a local, offline notes app that encrypts everything.
No cloud. No accounts. No tracking.

## Features

- End-to-end encryption
- Local storage only
- No account required
- Open source

## Installation

\```bash
flatpak install flathub com.github.marcelosalvador.Clavis
\```

## Usage

Launch clavis and start typing.
Everything is encrypted automatically.

## License

MIT
```

## Language & Style

### Words to use

| ✅ Use | ❌ Avoid |
|---|---|
| Simple | Simplistic |
| Local | Offline-only |
| Private | Secure |
| Built to last | High-quality |
| Made with care | Handcrafted |
| Tools | Solutions |
| Things | Products |

### Signature phrases

- "Things built to last."
- "Simple things, made with care."
- "Local. Private. Yours."
- "No cloud. No accounts. No compromise."
- "Built to protect what matters."

### General tone

- **Don't use:** Exclamation marks (!) in excess
- **Don't use:** Emojis in technical contexts
- **Use:** Correct punctuation
- **Use:** Short, clear sentences
- **Use:** Correct English (no grammatical errors)
